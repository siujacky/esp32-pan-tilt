Caution — servo power Never power servos from the ESP32's 3V3 or USB 5 V rail. SG90s take an external 5 V supply; the LX-16A takes 6.0–8.4 V (7.4 V nominal) on its own leads. Tie every supply ground to ESP32 GND — a common ground is mandatory.

The LX-16A voltage ladder

4.5V ──── 6.0V ══════ 7.4V ══════ 8.4V ──────────── 12V+ alarm-min spec floor NOMINAL spec ceiling damage (below this: weak, buzzy, hunting) (motor cooks)

The Voltage limit numbers in the servo editor (e.g. 4500–14000 mV) are the servo's alarm window — when to flash its LED and cut its own torque — not an operating rating. Factory-wide values mean "never complain". Once running at 7.4 V, tighten the window to about 6000–8500 so the protection actually protects.

3First start

  • On power-up the rig glides both axes to their home angles, then tries your WiFi for ~15 s (status LED fast-blinks).
  • Joined: browse to http://pantilt.local (mDNS) — or the IP on the OLED Connection page. LED solid. Firmware updates can be wireless from here on (pio run -e esp32ota -t upload).
  • No WiFi: it opens hotspot ESP32-PanTilt (pass pantilt123) at 192.168.4.1. LED slow-blinks. Provision your network from the web page (System tab → WiFi setup → Scan → join); it saves and reboots onto your network.

4Web control

Open the device IP in any browser. Everything is served from the ESP32 — no internet needed.

Main screen

  • Target tabs — PWM · Serial · Both: which servo set the D-pad drives. Each target keeps its own position, limits, home and speed.
  • D-pad — arrows nudge (hold to repeat); center ⌂ glides home.
  • Speed / Step slider — degrees per nudge.
  • Presets — four saved framing shots per servo-set. Tap a slot to glide there; arm Save to… (or Clear…) then tap the slot. The OLED has the same four slots on its last MENU page (Confirm = recall, A = save).

The display + joystick form a phone-free cockpit with two modes. Screens below are rendered 1:1 from the firmware's draw code.

The stick's center-click (OK) is deliberately unused — it's stiff and nudges the stick. All four actions are remappable from the web page only, so a bad map can never lock you out. Buttons fire on press-down (no need to wait for release), presses count as activity for the DRIVE idle timer, and every press flashes its hint inverted in the bottom bar (see Fig. 2) — instant feedback that the click registered.

  • Switch modes on the OLED Config page or the web Joystick tab.
  • Switch which servo set the stick flies (PWM / SERIAL / BOTH) on the Config page's Target row — or the web page's target tabs; they're the same setting.
  • Glitch-proof input: failed or inconsistent I²C reads are discarded, never interpreted as stick motion. After 100 consecutive failures the stick is declared offline until reboot.
  • Remapping the four buttons is web-only by design — the stick can't rebind itself.

7Smart-servo features (LX-16A backend)

Auto-trim — the staircase

An undervolted or loaded servo can land short of its commanded angle and grind against the gap. After every move settles, the firmware reads where the servo actually landed; if it's ≥2° short it re-commands past the target by the shortfall (up to two bumps), then remembers the overshoot that worked — per axis, per direction — and applies it to the first command next time. Inspect or reset the learned values at GET /lxcal.

Accept-reality park

If the staircase runs out of bumps with ≤2° of error left, the rig adopts the servo's reported position as the truth and re-commands at it — the motor rests instead of pushing forever, and the displays show the real angle.

Torque release when parked

Serial → Main → "Torque when parked". Three seconds after a move settles, torque releases — fully silent, zero hold current. Any new command re-engages it first. Caution: a released axis won't hold an unbalanced load against gravity — keep "Hold" for a heavy tilt.

Range test with collision watch

The web Test tab — and the Test page on the OLED (always the last MENU page: pick a servo, Confirm on Run test) — sweeps any single servo across its full 0–180° travel at 10°/s — soft limits deliberately bypassed, because that's what a range test is for. While a test runs, every other control (joystick, D-pad, home, auto-trim) is locked out. Serial servos are collision-watched: if the measured angle stops following the command (>8° gap, ~1 s of no progress), the servo instantly backs off 5° against its direction of travel and the whole system halts until you press Stop / clear halt — on the web, or Confirm/Back on the joystick, which act as a physical STOP button whenever a test is running. PWM servos have no feedback — their sweep runs blind, so keep a hand near the power.

Caution A range test intentionally ignores your soft limits. Clear the rig's surroundings first; the slow speed and collision watch are the safety net, not a guarantee.
Verified Commanded 90° → measured 89–90° closed-loop on this rig; trim, park, release, and a full 0→180→park range test with live tracking (cmd/actual within 3–5°) all exercised on hardware against a live LX-16A — including a real collision-watch trip (synthetic obstacle at 84°: backed off to 89°, halted, all motion locked, clean sweep after the obstacle was removed).

8Adding a second servo

Every LX-16A ships as ID 1, so program the newcomer before joining the bus.

1 Serial → IDs → Bus scan confirm what's already there (your first servo: ID 1) 2 connect ONLY the new servo unplug the first one for a moment 3 IDs → Program servo ID → 2 uses the safe lone-servo flow, verifies after writing 4 reconnect both → Bus scan should list ID 1 and ID 2 5 IDs → Link servo IDs point Tilt at ID 2 6 Detail → pick ID 2 set its limits / trim / alarm window
